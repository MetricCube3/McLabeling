# McLabeling Changelog

---

## v0.2.1 (In progress)

**新增功能**

- 🤖 **LocateAnything 自动标注**：集成 NVIDIA LocateAnything-3B 大模型，无需训练，直接使用项目标签名称进行零样本目标检测与边界框标注
- 🔀 **标注弹窗内模型切换**：点击"自动标注"按钮后，在确认弹窗中通过按钮切换 YOLO / LocateAnything 自动标注模型
- 💾 **LocateAnything 显存管理**：模型管理页面新增显存管理区块，支持手动卸载已加载的 LocateAnything 模型以释放 GPU 资源

**优化**

- ⚡ **推理前图像降采样**：对高分辨率视频帧在LocateAnything推理前自动限制最大边长（1344px），防止 OOM

---

## v0.2.0 (2026-06-25) 

**重构**

- 前后端代码模块化改造

**新增功能**

- ✨ **增加手动标注模式**：增加矩形框和多边形标注功能
- 🔄 **增加OBB旋转框标注**：支持三点法绘制旋转矩形框，适用于倾斜物体标注
- 📦 **新增YOLO-OBB格式导出**：单独导出OBB标注数据，支持YOLOv8 OBB模型训练
- ✏️ **标注对象编辑**：支持对已标注对象进行顶点拖拽、插入顶点、删除顶点、矩形/OBB整体平移等编辑操作

**优化**

- 🎨 **自动标注按钮侧边化**：移至绘制模式侧边栏，操作更集中
- 🔀 **保存自动跳转开关**：新增保存后是否自动跳转下一帧的开关控件
